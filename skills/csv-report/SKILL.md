# CSV report

Never print a whole CSV into your context. A bundled script does the counting
and writes the report file for you.

## Steps

1. Run the script on the file:

   ```bash
   python3 /skills/csv-report/scripts/csv_report.py <path-to-csv> --group-by <column> --amount <column>
   ```

   It prints a short summary to stdout and writes the full report to
   `/workspace/reports/<csv-basename>.md`.

2. Read only the stdout summary. Do not open the CSV or the report with
   `read_file` unless the script fails.

3. Reply to the user with exactly:
   - the path of the report,
   - the row count,
   - the top group by total amount.

## Conventions the script enforces

- Amounts are shown with two decimals and the `EUR` suffix.
- Groups are sorted from highest to lowest total.
- The report title is `# Report: <csv-basename>`.
- The report ends with a `Generated by csv-report skill` line.
